# Ledger Login

A free admin sign-in page in plain HTML, CSS and JavaScript. No framework, no dependencies.

Preview: https://profound-genie-ff55f6.netlify.app

## Use it

1. Download or clone this repository.
2. Open the HTML file in your browser.
3. Edit it and connect it to your own backend.

## Want the rest?

This is one page from Ledger, a four-page SaaS admin dashboard kit (dashboard, customers, settings, login): https://vaazro.gumroad.com/l/ledger
